# Proyecto Gym

Aplicación web moderna para la gestión de rutinas, ejercicios y seguimiento de entrenamiento físico.

---

# Descripción

Proyecto Gym es una plataforma enfocada en la administración y visualización de entrenamientos, diseñada para ofrecer una experiencia moderna, dinámica y responsive para usuarios interesados en el fitness y control de rutinas.

El proyecto incorpora una interfaz moderna, navegación fluida y componentes reutilizables orientados a aplicaciones deportivas y de gimnasio.

---

# Características principales

## Gestión de entrenamientos

- Visualización de rutinas.
- Organización de ejercicios.
- Distribución por grupos musculares.
- Seguimiento de progreso.

## Diseño moderno

- Interfaz responsive.
- Diseño adaptable a móviles.
- Componentes reutilizables.
- Navegación fluida.

## Experiencia visual

- UI enfocada en fitness.
- Animaciones modernas.
- Tarjetas dinámicas.
- Diseño limpio y profesional.
